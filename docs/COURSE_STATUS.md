# 课程实验与本仓库的关系

本仓库实现用户级线程调度与 I/O 等待的专题原型，主要延伸第 4 章用户级线程、进程/线程通信和第 7 章 I/O 多路复用。它不是全部课程作业代码的合集。

课程作业在独立的 `course-labs/` 实验包中整理。原始学生框架、讲义及其派生实验代码没有整体加入本公开仓库。请向队内共享文件的同学获取 `openEuler课程实验-含拓展验收版.zip`；克隆当前仓库不会得到该实验包。

## 课程范围

| 章 | 实验 |
| --- | --- |
| 1 | 安装/使用 openEuler；GCC；社区与 git |
| 2 | strace；异常；iSulad 构建与运行 |
| 3 | 虚拟地址空间；malloc；缺页、栈增长与溢出 |
| 4 | fork/exec/wait；pthread；用户级线程；进程/线程通信 |
| 5 | 经典同步；死锁；内存顺序 |
| 6 | 文件操作与偏移；目录、元数据、权限与链接；挂载与 VFS |
| 7 | 字符设备；阻塞/非阻塞/多路复用；块设备与网络；内核模块；eBPF |

课程包的拓展包括自编编译流程、分段求和、请求响应通信、三资源死锁、显式内存屏障、多输入源事件循环、同接口设备对照、参数化模块和新 eBPF tracepoint。具体程序、对照和实际结果以逐项拓展报告为准。

## 队友拿到课程包后

1. 解压，进入 `course-labs/`，先读该目录的 README。
2. 阅读 `reports/实验报告.md` 和 `reports/拓展任务验收.md`，用链接核对原始证据。
3. 在 openEuler 客户机中，以普通账号运行 `python3 scripts/run_course.py`；需要拓展时运行 `python3 scripts/run_extensions.py`。
4. 高权限实验按包内说明，在专用客户机运行 `sudo python3 scripts/run_advanced.py`。它涉及工具安装、容器服务以及短暂的模块/eBPF 加载，不是本仓库 `make check` 的一部分。
5. 补本人姓名、学号、班级及教师模板，保留课程来源和 AI 辅助记录，不将他人 PR 或已生成的本地补丁冒称为本人已被上游接受的贡献。

普通用户权限对照不应以 root 运行。课程包保留了预期 SIGFPE、SIGSEGV 和死锁超时等现象；这些与意外失败分别标注。

## 专题项目如何与课程衔接

先完成课程的 first-ready 用户线程框架与 FIFO/select 观察，再用本仓库比较轮转调度和事件驱动等待。进一步性能分析在优化分支，须区分完整记录/无记录模式、纯调度/共享等待负载，以及本机虚拟机/CI 容器环境。

课程中的内核模块和 eBPF 观察属于独立实验；本专题运行时不依赖它们，也不通过修改内核实现用户线程调度。
