## 换机器时的环境参考

源码起步不需要新增资料。完成真实验证需要一台可用的 openEuler 环境。
推荐先用 openEuler 24.03 LTS x86_64 虚拟机，初始可分配 2 vCPU、4 GiB 内存和 20 GiB 磁盘，实际按主机容量调整；这是开发建议，不是竞赛硬性要求。

准备好后，提供以下非敏感输出即可判断环境是否合适：

```sh
cat /etc/os-release
uname -a
getconf GNU_LIBC_VERSION
gcc --version
make --version
python3 --version
```

不要在聊天中发送密码、私钥或令牌。可以由用户在虚拟机内运行 `make check` 并粘贴完整输出；如之后希望自动运行，再配置用户授权的连接方式。

可选但有帮助的信息：参赛人数、每周可投入时间、正式提交日期，以及指导教师的选题意见。
